    AI-Based Fake Identity & Document Screening System
    
                            
    An educational, software-only computer vision screening framework designed to perform preliminary document analysis using Optical Character Recognition (OCR), heuristic format checking, and non-forensic image quality assessment.
    

                            
    
                                
    Automated Screening Workflow
    
                                
    
                                    
    
                                        01
                                        
    Upload & Validation
    
                                        
    Validates file type (JPG/PNG), size (max 16MB), and verifies image pixel data with OpenCV.
    
                                    
    
                                    
    
                                        02
                                        
    OCR Extraction
    
                                        
    Preprocesses document (grayscale, CLAHE contrast, noise reduction) and extracts text via EasyOCR.
    
                                    
    
                                    
    
                                        03
                                        
    Classification & Formats
    
                                        
    Identifies document category and verifies expected structural syntax (PAN, 12-digit, etc.).
    
                                    
    
                                    
    
                                        04
                                        
    Consistency & Quality
    
                                        
    Validates field presence, date ranges, image blur/sharpness, and non-forensic capture anomalies.
    
                                    
    
                                
    
                            
    

                            
    
                                
    Important Project Disclaimer
    
                                
    This application is developed strictly as a preliminary screening and educational tool. It does not connect to legal government databases, does not upload personal data to cloud services, and does not claim to definitively prove document genuineness or forgery.
